# OT Packet Lens

OT/ICS network traffic analysis using Wireshark/TShark.

## Project Contents

- `1-QUICK_START.html` - Quick-start guide
- `2-README.html` - Project documentation
- `4-OT Packet Lens Web App and CLI/` - Web application and command-line tools
- `OT Packet Lens_ OT_ICS Analysis Infographic.png` - Project infographic

## Industrial Protocols

The project analyzes industrial network traffic, including
Modbus/TCP, S7comm, EtherNet/IP, DNP3, and other supported protocols.

## Windows Portable Application

The Windows Portable Toolkit is distributed separately
through GitHub Releases.
