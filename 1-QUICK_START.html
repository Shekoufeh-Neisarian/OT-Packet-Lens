Choose How to Run

🖥️ Windows Desktop Portable application with bundled runtime dependencies. No separate Python or Wireshark installation.
🌐 Web Dashboard Interactive local application. Requires Python and Wireshark/TShark.
⌨️ Command Line Analyze captures directly from PowerShell. Supports automated report exports.

01 · Windows Portable Desktop

Recommended for first-time users.

  1. Open the folder 3-OT Packet Lens Windows Portable Toolkit.
  2. Double-click OT Packet Lens.exe.
  3. Load a PCAP or PCAPNG capture.
  4. Explore devices, protocols, and communications.
  5. Export the investigation results.

Keep the executable and its accompanying runtime folders together. Do not move the EXE alone.

02 · Web Dashboard

Requirements: Windows 10/11, Python 3.10+, and Wireshark/TShark.

Open PowerShell in the main Project 9 folder:

cd ".\4-OT Packet Lens Web App and CLI"
python start.py

On the first run, the launcher prepares the Python environment and starts the local dashboard.

Load a capture file from the top right list or from your computer to begin the analysis.

03 · Command-Line Analysis

From the main Project 9 folder:

cd ".\4-OT Packet Lens Web App and CLI"

python start.py --setup-only

.\.venv\Scripts\python.exe cli.py "C:\path\to\capture.pcap" --export all --output-dir reports

Replace the example path with the actual PCAP or PCAPNG location.

Command Options

Option Description
--setup-only Prepares the Python environment
--export all Generates all supported report formats
--output-dir reports Saves output inside the reports directory

04 · Investigation Workflow

Load PCAP → Explore Devices and Protocols → Investigate Communications → Export Results
